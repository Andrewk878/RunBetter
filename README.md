# Run Better

A simple personal wellness dashboard for running, nutrition, sleep, strength, weekly planning, and a customizable page.

## Open locally

Open `index.html` in a modern browser. There is no build step or account setup. Activity and preferences are saved in your browser on this device using local storage.

## Included areas

- **Overview:** weekly running progress, recommended guidance, and links to all areas.
- **Running:** log distance, duration, effort, date, and a note.
- **Nutrition:** keep meal, snack, or hydration notes.
- **Sleep:** track hours, how rested you feel, and an optional note.
- **Strength:** record exercises, sets, reps, and notes.
- **Calendar:** plan sessions or rest days and see the current week.
- **My page:** add and remove activity widgets for a personal dashboard.

Choose Beginner or Experienced in the top bar to change running guidance and the weekly target. Information stays in this browser on this device; there are no accounts or cloud sync.
